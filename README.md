# emotion-detection-using-AI

## 📌 Project Overview

This project is a **Machine Learning and Natural Language Processing (NLP)** based application that identifies the emotion expressed in a given text sentence.

The user enters a sentence as input, and the trained Machine Learning model analyzes the text and predicts the most suitable emotion.

## 🎯 Objective

The main objective of this project is to understand and implement **NLP and Machine Learning techniques for emotion classification**. It demonstrates how computers can analyze human language and identify emotions from textual data.

## ✨ Features

* Accepts a sentence as user input
* Processes and analyzes the text
* Uses NLP techniques for text classification
* Predicts the emotion expressed in the text
* Displays the predicted emotion as output

## 🛠️ Technologies Used

* **Python**
* **Natural Language Processing (NLP)**
* **Machine Learning**
* **Pandas**
* **Scikit-learn**

## ⚙️ Working Process

```text
User Input
    ↓
Text Preprocessing
    ↓
Feature Extraction
    ↓
Machine Learning Model
    ↓
Emotion Prediction
    ↓
Output
```
